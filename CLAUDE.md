# figma-tools

Figma plugin + build tooling that imports design tokens into Figma as variable collections. Collections are described by JSON files and compiled into the plugin; you pick which ones to import each run.

## What it does

Ships with three collections, each defined by a JSON file in `tokens/`:

- **Tailwind Spacing** — full Tailwind v4 scale (0–96), single "Default" mode, fixed px values (`tokens/tailwind.json`, static)
- **Utopia Spacing** — fluid spacing tokens from [Utopia](https://utopia.fyi), two modes: "xl — 1280px" and "xs — 480px" (`tokens/utopia.json`, generated from `.env`)
- **Typography** — font weight/family/size tokens, grouped (`font/weight/…`, `font/family/…`, `font/size/…`), two modes: "xl" and "xs" (`tokens/typography.json`, static)

## Project structure

```
.env                     # UTOPIA_SPACING URL (only config needed)
build.js                 # Regenerates tokens/utopia.json from .env, compiles tokens/*.json → plugin/code.js
tokens/
  tailwind.json          # Static
  utopia.json            # Generated by build.js — do not hand-edit
  typography.json        # Static
figma-spacing-import.js  # Alternate: pushes tokens/utopia.json straight to Figma via the REST API
plugin/
  manifest.json          # Figma plugin manifest
  code.js                # Plugin code (runs inside Figma's sandbox)
  ui.html                # Collection-selection checklist shown when the plugin runs
```

## Collection JSON schema (`tokens/*.json`)

```json
{
  "name": "Typography",
  "modes": ["xl", "xs"],
  "variables": [
    { "name": "font/weight/light", "type": "STRING", "values": { "xl": "Light", "xs": "Light" } },
    { "name": "font/size/5xl", "type": "FLOAT", "values": { "xl": 120, "xs": 77 }, "description": "optional" }
  ]
}
```

- `modes`: ordered; the first entry becomes the collection's default mode, the rest are added via `addMode`.
- `variables[].name`: the literal Figma variable name. A `/` creates nested groups in the Figma sidebar (e.g. `font/weight/light`).
- `variables[].type`: Figma `resolvedType`. `FLOAT` and `STRING` are implemented/tested; `BOOLEAN`/`COLOR` should work through the same `createVariable` call but aren't exercised by any current file (`COLOR` needs `{r,g,b,a}` values, 0–1 floats).
- `variables[].values`: must have one entry per declared mode.

`build.js` validates every `tokens/*.json` file before compiling (name present, modes non-empty, variable names have no dots, no duplicate names, every mode has a value) and fails with a per-file error message if not.

## Workflow

### Adding a new collection

1. Create `tokens/<name>.json` following the schema above.
2. Run `npm run build`.
3. Re-run the plugin in Figma and check the new collection in the selection list.

### Updating Utopia spacing tokens

1. Adjust settings at [utopia.fyi/space/calculator](https://utopia.fyi/space/calculator)
2. Copy the full URL into `.env` as `UTOPIA_SPACING`
3. Run `npm run build` — this regenerates `tokens/utopia.json` and recompiles `plugin/code.js`
4. Re-run the plugin in Figma to apply

### Running the plugin in Figma

1. In Figma: **Plugins → Development → Import plugin from manifest...**
2. Select `plugin/manifest.json`
3. Run via **Plugins → Development → Import Spacing Variables**
4. Check the collections you want in the popup, then click Import

If a collection already exists from a previous run, delete it in Figma first before re-importing it.

## Key constraints

- **Figma Plugin API does not allow dots in variable names.** Tailwind fractional values use underscores instead: `0_5`, `1_5`, `2_5`, `3_5`. `build.js` rejects any `tokens/*.json` variable name containing a dot.
- **The Figma REST API requires a Professional plan** for `file_variables:write`. The plugin approach works on all plans; `figma-spacing-import.js` is the REST-API alternate for accounts that do have that plan.
- `plugin/code.js` runs in Figma's sandbox — it has no access to the filesystem or `.env`. Only `build.js` and `figma-spacing-import.js` (both run under Node) read files.
- The `tokenCollections` array in `plugin/code.js` is generated — do not edit it by hand. The sentinel comment `// GENERATED` marks the block that `build.js` replaces. It's compiled from every file in `tokens/`.
- `tokens/utopia.json` is itself generated (by `build.js`, from `.env`) — don't hand-edit it either; edit `.env` and rerun `npm run build`.

## .env

```
UTOPIA_SPACING = <utopia calculator URL>
```

No API tokens required for the plugin flow. `figma-spacing-import.js` additionally needs `FILE_KEY` and `FIGMA_TOKEN` (a Professional-plan file and a personal access token with `file_variables:write`).
